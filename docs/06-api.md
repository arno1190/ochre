# 06 — HTTP API

## Conventions
- **Base paths:**
  - `/api` for the app, used by the SPA and PATs;
  - `/api/public` for the careers site (no auth);
  - `/auth` for sign-in;
  - `/scim/v2` for provisioning;
  - `/mcp` for agents.
- **Format:** JSON, `snake_case`. Ids are UUID strings. Timestamps are RFC 3339 UTC.
- **Auth:** the session cookie plus the `X-Ochre-CSRF` header on writes, **or** `Authorization: Bearer ochre_pat_…`.
- **Errors:** `application/problem+json`:
  ```json
  {"type":"https://ochre.dev/errors/<code>","title":"…","status":409,"code":"duplicate_active_application","detail":"…","fields":{"email":"already used by another candidate"}}
  ```
  `code` is a stable machine string, and the UI maps codes to copy. Error responses never echo submitted values.
- **Authorization results:**
  - `401` when not signed in;
  - `404` when the resource exists but the caller cannot reach it (**[New]**: v0 returned 403, which revealed existence);
  - `403` when it can be reached but the action needs more capability.
- **Pagination:** `?limit=` (default 50, max 200) and `?cursor=` (opaque). Responses are `{items:[…], next_cursor: str|null}`.
- **Concurrency:** writes to Positions, Candidates, Scorecards and templates accept `If-Match: <updated_at>`. A mismatch returns `412`.
- **Idempotency:** `POST` endpoints that send mail accept `Idempotency-Key` (24 h).
- **Rate limits:** per session or PAT, 600 requests per minute. Auth endpoints and the public endpoints have their own limits (03, 05).
- **OpenAPI:** generated by FastAPI at `/api/openapi.json`. The TypeScript client is generated from it at build time (`openapi-typescript`). **No hand-written client** (v0's was 1,600 lines).

Permission shorthand, as in 03: `A` admin, `Rc` recruiter or admin, `M` manage on the Position, `R` read, `Self` the caller's own resource, `Any` any signed-in active user.

## SCIM 2.0 (`/scim/v2`)

- RFC 7643 and 7644 subset:
  - `ServiceProviderConfig`, `ResourceTypes`, `Schemas`;
  - `Users`: GET with list/filter on `userName eq`, POST, GET by id, PUT, PATCH (`active`, `name`, `emails`, `displayName`, `externalId`), DELETE meaning deactivate;
  - `Groups`: GET, POST, PATCH members, DELETE.
- Group `displayName` → Global Role through `settings.auth.providers[].role_mapping`.
- Auth: a bearer SCIM token (`access_tokens.kind='scim'`).
- Tested against the Entra provisioning validator checklist and Okta's SCIM test suite. The test cases are written as pytest fixtures.

## MCP (`/mcp`)

- Streamable HTTP transport (MCP spec 2025-06-18 or later), with bearer PAT auth. A read-only PAT exposes only the read tools.
- Every tool calls the same service functions as the REST API, so permissions and Events are identical. `via` = `mcp:<prefix>`.
